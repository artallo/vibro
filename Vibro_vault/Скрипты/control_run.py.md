# control_run.py — прогон контрольных точек, «до» и «после»

## Для чего

Любая правка метода в [[stable_spectrum.py]] проверяется на реальных
записях: что было найдено до правки, что после. Скрипт прогоняет
[[Контрольные точки]] одной командой и сравнивает два таких прогона.
Появился 02.10.2026; до этого такие сравнения делались разовыми
скриптами по всем точкам и при трёх разрешениях.

Список точек лежит в `control_points.toml` в корне репозитория: имя точки,
папка, пробы. Пробы — только частоты, найденные **до** этих записей, в
другой точке или в другой день. Частот здания в коде нет.

## Что делает

1. Каждую точку разбирает при одном разрешении, nperseg из
   `[stable_spectrum] nperseg` в `config.toml` (2048). Если там несколько
   значений, скрипт отказывается и просит задать одно или ключ `--nperseg`.
   Подпапок `nperseg_<n>` и картинок `figure_compare_*` нет.
2. Каждый прогон точки отдельно и все прогоны точки вместе, как `--pool`.
   Если прогоны сняты при разной частоте опроса (Эрвье, 1 этаж), объединение
   пропускается, причина пишется в сводку.
3. Ключи метода передаются в каждый разбор без изменений.
4. Результат — в `stable_results/_control/<вариант>/`. Повторный прогон с
   тем же именем заменяет прежний целиком.

| Что | Где |
|---|---|
| Сводка для чтения: пики каждой записи и объединения, пробы, пропуски | `control_summary.txt` |
| Все пики одной таблицей | `control_peaks.csv` |
| Все пробы | `control_probes.csv` |
| Обычный вывод stable_spectrum.py по точке | `<точка>/runs/`, `<точка>/pool/` |
| Сравнение двух вариантов | `stable_results/_control/compare_<A>_<B>.txt` |

## Сравнение

`--compare A B` сопоставляет пики двух прогонов на одной точке, в одной
записи и на одной оси, если частоты отличаются не больше `--tolerance`
(0,2 Гц), ближайшие первыми. Выводит три списка: пропавшие (только в A),
новые (только в B) и оставшиеся с z «до → после», сдвигом частоты и
пометкой k/N у объединений. Точки, которые есть только в одном из
прогонов, не сравниваются и перечислены отдельно.

## Ключи

| Ключ | По умолчанию | Что |
|---|---|---|
| `вариант` | — | имя прогона, например `before` или `after` |
| `--compare A B` | — | сравнить два прежних прогона вместо нового |
| `--points NAME …` | все | только эти точки из списка |
| `--points-file` | `control_points.toml` | другой список точек; папки в нём считаются от места файла |
| `--nperseg` | из `config.toml` | одна длина отрезка |
| `--alpha` | 0,01 | как в [[stable_spectrum.py]] |
| `--band MIN MAX` | из `config.toml` | полоса |
| `--baseline-window` | из `config.toml` | ширина базы |
| `--min-distance` | из `config.toml` | зазор между пиками |
| `--separation-sigma` | из `config.toml` | порог провала между близкими пиками |
| `--tolerance` | 0,2 Гц | для `--compare`: насколько может разойтись частота одного пика |
| `--output` | `stable_results/_control` | куда писать |

## Примеры

```bash
python control_run.py before
python control_run.py after --separation-sigma 3
python control_run.py --compare before after
python control_run.py quick --points resp40_st2_f5 ervye_f1
```

Все семь точек считаются около 50 секунд.
