# band_power.py — мощность в полосе против шума датчика

## Для чего

[[stable_spectrum.py]] ищет **узкие** пики: каждый бин сравнивается со
скользящей медианой соседей шириной 5 Гц. Горб шире 2–2,5 Гц становится
своей же базой и в отчёт не попадает, а слабый горб под шумом датчика
поднимается над ним на доли дБ. Этот скрипт отвечает на другой вопрос:

> сколько мощности в полосе сверх той, что даёт сам датчик?

Так находятся широкие горбы, которые узкий поиск теряет. Появился
01.10.2026 после разбора горба 9–13 Гц на Республики 40, см.
[[2026-10-01 Республики 40, сверка с Байкалом]] и раздел «База и широкие
структуры» в [[Устойчивый спектр — метод]].

## Как считает

1. Каждая запись режется на периодограммы по пакету (окно Ханна,
   nperseg не больше пакета). Стартовый пакет выбрасывается так же, как в
   [[stable_spectrum.py]]. Записи одной точки объединяются пакет к пакету.
2. Мощность в полосе — сумма периодограммы по полосе, отдельно для каждого
   пакета. Среднее и погрешность берутся из разброса между пакетами.
3. Опора — та же величина по записям, где только шум датчика (`--noise`),
   или по другой точке (`--reference`), например по цоколю.
4. `z = (P − P_опоры) / √(погр² + погр_опоры² + сист²)`. Систематика
   `сист` задаётся ключом `--noise-sys-db`.
5. Полосы задаются явно (`--bands`) или сканируются окнами `--scan` Гц с
   шагом в пол-окна по `--band`. Порог — Бонферрони по всем полосам и
   осям точки, как в [[stable_spectrum.py]]. Соседние окна сканирования
   перекрываются наполовину, поэтому поправка с запасом. Подряд идущие
   значимые окна сливаются в одну структуру.

Зашитых частот нет: полосы приходят из командной строки или из
сканирования.

## Ключи

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `--point МЕТКА ПУТЬ …` | обязательно | точка измерения: метка, затем файлы, шаблоны `*` или папки; повторять для каждой точки, до восьми |
| `--noise ПУТЬ …` | — | записи, где только шум датчика; нужно ровно одно из `--noise` и `--reference` |
| `--reference МЕТКА` | — | сравнивать не с шумом, а с другой точкой из `--point` |
| `--bands LOW-HIGH …` | нет | заданные полосы, например `9.5-13 9-12` |
| `--scan ШИРИНА` | 2 Гц, если нет `--bands` | сканировать окнами этой ширины |
| `--band MIN MAX` | из конфига, 0.2 15 | где сканировать |
| `--plot-band MIN MAX` | 0.5 30, расширяется под полосы | что показать на рисунке |
| `--nperseg N` | 1024 | длина отрезка, не больше пакета |
| `--baseline-windows Гц …` | из конфига, 10 | окна скользящей медианы на рисунке и в таблице заданных полос; для сравнения задать несколько, например `5 10 15` |
| `--noise-sys-db` | 0 | систематическая погрешность опоры в дБ |
| `--alpha` | 0.01 | вероятность ложной находки на точку |
| `--output папка` | `stable_results/band_power_<время>/` | куда писать |

Шаблоны `*` скрипт раскрывает сам, поэтому они работают и в PowerShell.

## Примеры

Республики 40, три точки против шума датчика, заданные полосы и
сканирование:

```bash
python band_power.py --point "Лестница 1, 5 этаж" "tumen_results/261001_Ростелеком на Республики 40/лестница 1, 5 этаж/*_raw.npz" --point "Лестница 2, 5 этаж" "tumen_results/261001_Ростелеком на Республики 40/лестница 2, 5 этаж/*_raw.npz" --point "Цоколь" "tumen_results/261001_Ростелеком на Республики 40/цоколь/*_raw.npz" --noise "tumen_results/20260912_*_raw.npz" "tumen_results/20260916_*_raw.npz" --bands 9.5-13 9-12 --scan 2 --band 0.5 30 --baseline-windows 5 15 --output stable_results/261001_resp40_band_power
```

Пятый этаж против цоколя вместо шума датчика:

```bash
python band_power.py --point "5 этаж" "путь/к/записям этажа" --point "Цоколь" "путь/к/записям цоколя" --reference "Цоколь" --bands 9.5-13
```

Новая запись, только сканирование полосы анализа:

```bash
python band_power.py --point "новая" results/<запись>_raw.npz --noise "tumen_results/20260912_*_raw.npz" "tumen_results/20260916_*_raw.npz"
```

## Что пишет

| Файл | Что |
|---|---|
| `band_power_report.txt` | отчёт, он же печатается в консоль |
| `band_power.csv` | все полосы: мощность, опора, превышение, z, порог, сигнал |
| `figure_band_power.png` | амплитудный спектр каждой точки и опоры по трём осям, базы первой точки, заданные полосы закрашены, найденные структуры — цветные полосы внизу, по ряду на точку |

## Как читать отчёт

| Столбец | Смысл |
|---|---|
| `Excess dB` | во сколько раз мощность в полосе больше опоры, в дБ |
| `z`, `thr` | превышение в единицах погрешности и порог |
| `Signal ug/rtHz` | плотность того, что лежит сверх опоры: сигнал под шумом |
| `Spread dB` | насколько записи опоры расходятся между собой в этой полосе: честный размер `--noise-sys-db` |
| `base 5 Hz`, `base 15 Hz` | среднее превышение над скользящей медианой: сколько полосы видит узкий поиск |
| `Verdict` | `above reference` или `not above` |

В разделе `Scan` — слитые структуры: диапазон и самое сильное окно в нём.

> [!important] Сканирование находит любое превышение, не только горбы
> Узкая форма или линия техники тоже поднимает мощность своего окна. Чтобы
> понять, широкая структура или узкая, сравнить с отчётом
> [[stable_spectrum.py]]: если там в этом месте узкий пик, это он; если
> пусто, а здесь превышение — это широкая структура или шум выше модели.

## Систематика опоры

Без `--noise-sys-db` z учитывает только случайную погрешность. Шум датчика
от записи к записи гуляет: по записям 12.09 и 16.09 разброс в полосах
0,10–0,14 дБ, максимум 0,30 дБ. Для осторожного вывода задавать
`--noise-sys-db` около значения из столбца `Spread dB`, например 0,15.

Пример, Республики 40, Z 9–12 Гц:

| Точка | z без систематики | z при `--noise-sys-db 0.15` |
|---|---|---|
| Лестница 1, 5 этаж | 8,8 | 5,9 |
| Лестница 2, 5 этаж | 4,9 | 3,3 |
| Цоколь | 3,6 | 2,2, ниже порога |

## Проверка

- Тесты `test_band_power.py`, см. [[Тесты]]: синтетический горб находится
  на своей оси и не на других; сканирование ставит его на место и не
  находит ничего в чистом шуме; база 5 Гц видит горб хуже, чем мощность в
  полосе; систематика снижает z; стартовый пакет выбрасывается; смешанные
  ODR отклоняются.
- 01.10.2026 на реальных данных: записи 16.09 и 17.09 (только шум) против
  модели шума по записям 12.09 — сканированием в полосе 0,2–15 Гц ничего
  не найдено.

## Ограничения

- Все записи точек и опоры должны иметь одну частоту опроса, разница не
  больше 0,5 %. Иначе скрипт остановится и перечислит файлы.
- Модель шума — это записи конкретного датчика. С другим экземпляром
  ADXL355 нужны его собственные шумовые записи.
- Опора по шуму видит любую вибрацию, не только формы здания: транспорт,
  технику, шаги. Отличить отклик здания от возбуждения помогает опора по
  нижней точке (`--reference`), лучше при одновременной записи.
- Узкие пики в полосе тоже дают превышение; ширину структуры
  определяет сравнение с [[stable_spectrum.py]].
