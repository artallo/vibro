# family_analysis.py — семейства частот

## Для чего

Собирает «доверенные» области старого детектора из всех временных окон
replay и группирует их в повторяющиеся семейства частот. Отвечает на
вопросы, когда во времени структура присутствовала и возвращается ли она
в разных измерениях. Частоты здания в код не зашиты.

Входные данные готовит [[main.py]] в режиме `--replay`.

## Ключи

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `папки replay или отчёты .txt` | обязательно | одна или несколько папок `replay_results/<запись>`; старые отчёты `.txt` без сырых данных входят как одно окно своей раскладки |
| `--output папка` | `family_results/<первая папка>/`, для нескольких `family_results/multi_<время>/` | куда писать |
| `--link-tolerance-hz` | допуск ODR из replay, 0.40 при 250 | порог склейки в семейство |
| `--max-family-span-hz` | 2 × допуск | наибольший разброс частот внутри семейства |
| `--welch-nperseg` | 1024 | нужен для расчёта запаса по диапазону, 0,75 бина |
| `--linkage` | `average` | способ кластеризации; `complete` строже |

## Примеры

```bash
python main.py --replay "real_results/20260903_000346_ODR250_run01_raw.npz" --virtual-mode all
python family_analysis.py replay_results/20260903_000346_ODR250_run01_raw
python family_analysis.py replay_results/2026090*_raw results/<старый отчёт>.txt --output family_results/real_all_captures
```

## Что пишет

| Файл | Содержимое |
|---|---|
| `family_observations.csv` | каждая доверенная область с номером семейства |
| `family_summary.csv` | по семействам: центр, разброс, повторяемость по записям, медианы |
| `family_scale_profile.csv` | семейство × раскладка |
| `family_capture_matrix.csv` | семейство × запись |
| `family_pair_comparison.csv` | пары раскладок на одних и тех же пакетах |
| `family_metadata.txt` | параметры и метод |
| `figure_family_time_<запись>.png` | частота × время |
| `figure_family_occupancy.png` | заполненность семейств |
| `figure_family_freq_vs_med.png` | Freq против Med.Freq |

## Требования к методу, выработанные на раннем этапе

- Единица наблюдения — одна доверенная область в одном виртуальном
  прогоне; от одного прогона в семейство идёт один голос.
- Учитывать и `Freq`, и `Med.Freq`, и размах; ни одну из первых двух
  величин нельзя объявить единственно верной, см.
  [[Старый детектор — как он устроен]].
- Явно ограничивать ширину семейства, иначе цепочка 3,2 → 3,5 → 3,8 → 4,1
  слипается в одно бесконечно широкое семейство.
- Считать отдельно заполненность по раскладкам и повторяемость по
  независимым записям, см. [[Временные масштабы и нестационарность]].
- Сравнивать контролируемые пары раскладок на одних и тех же пакетах.
- Оставаться исследовательским слоем и не превращаться в новый критерий
  отбора, см. [[Философия и принципы]].

## Ограничения

- Вложенные раскладки одной записи делят пакеты, это не независимые выборки.
- Номера семейств меняются между запусками, сравнивайте по частоте.
- Семейства строятся поверх старого детектора с фиксированными порогами,
  поэтому на шумовых записях они собирают шум. См. [[Почему результаты скачут]].
