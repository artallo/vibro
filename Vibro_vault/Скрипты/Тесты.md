# Тесты

```bash
python -m unittest test_stable_spectrum test_overview_figure test_family_analysis test_band_power test_false_alarm_check
```

| Файл | Что проверяет |
|---|---|
| `test_stable_spectrum.py` | базовая линия, порог, отсутствие ложных пиков на шуме, поиск тона, половины, проверка записи, окна поддержки, `--probe`, разрешения nperseg, стыки пакетов, раскладка по папкам, ширина базы: вершина горба шириной 4 Гц при базе 10 Гц, узкая линия от ширины не зависит, конфиг и ключ `--baseline-window`; честный порог проб: разбор `Y:2.88`, порог по бинам окна, слабая линия проходит честный порог и не проходит слепой, сильный сосед на 0,6 Гц не отвечает за пробу, слияние кандидатов, подтверждение одного прогона другим и отказ подтверждать себя; объединение прогонов: отрезок не идёт через стык, окна поддержки внутри прогона, пометка 2/2 и 1/2, отказ при разной частоте опроса, отчёт `--pool`; 2048 по умолчанию из конфига |
| `test_overview_figure.py` | объединение папки (каждая запись режется сама), поиск тона, отказ на смешанных ODR и пустой папке, пропуск чужих файлов; тон при 2048 и 4096 и порог по независимым отрезкам, режим поиска с порогом 0,01 для сравнения, поиск провалов, папки `nperseg_<n>` |
| `test_family_analysis.py` | кластеризация семейств |
| `test_false_alarm_check.py` | мало ложных пиков на белом шуме, пробы не меняют поиск и редко выходят «present», окрашенный шум сохраняет рост Z, линия из шумовой записи не копируется в форму шума, интервал Уилсона, командная строка |
| `test_band_power.py` | синтетический горб находится на своей оси и не на других, сканирование ставит его на место и молчит в чистом шуме, база 5 Гц видит горб хуже мощности в полосе, систематика снижает z, стартовый пакет, отказ на смешанных ODR, опора по точке, папка как точка |

Проверка ложных пиков на сотнях шумовых записей идёт отдельным скриптом
[[false_alarm_check.py]], она дольше тестов. Результат 01.10.2026 при
базе 10 Гц: белый шум 0,7–1,7 %, окрашенный 1,7–4,0 % записей с ложным
пиком. Прежняя разовая проверка 16.09.2026 при базе 5 Гц: 3 из 300 при
1024 и 4 из 300 при 4096.
