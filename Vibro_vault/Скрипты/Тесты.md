# Тесты

```bash
python -m unittest test_stable_spectrum test_overview_figure test_family_analysis
```

| Файл | Что проверяет |
|---|---|
| `test_stable_spectrum.py` | базовая линия, порог, отсутствие ложных пиков на шуме, поиск тона, половины, проверка записи, окна поддержки, `--probe`, разрешения nperseg, стыки пакетов, раскладка по папкам |
| `test_overview_figure.py` | склейка папки, поиск тона, отказ на смешанных ODR и пустой папке, пропуск чужих файлов |
| `test_family_analysis.py` | кластеризация семейств |

Отдельная проверка вне тестов, 16.09.2026: на 300 записях чистого шума
ложный пик нашёлся в 3 анализах при nperseg 1024 и в 4 при 4096.
Ожидается около 3, то есть 1 %.
