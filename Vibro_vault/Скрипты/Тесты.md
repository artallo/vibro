# Тесты

```bash
python -m unittest test_stable_spectrum test_overview_figure test_family_analysis test_band_power test_false_alarm_check test_control_run test_main
```

| Файл | Что проверяет |
|---|---|
| `test_stable_spectrum.py` | базовая линия, порог, отсутствие ложных пиков на шуме, поиск тона, половины, проверка записи, окна поддержки, `--probe`, разрешения nperseg, стыки пакетов, раскладка по папкам, ширина базы: вершина горба шириной 4 Гц при базе 10 Гц, узкая линия от ширины не зависит, конфиг и ключ `--baseline-window`; честный порог проб: разбор `Y:2.88`, порог по бинам окна, слабая линия проходит честный порог и не проходит слепой, сильный сосед на 0,6 Гц не отвечает за пробу, слияние кандидатов, подтверждение одного прогона другим и отказ подтверждать себя; объединение прогонов: отрезок не идёт через стык, окна поддержки внутри прогона, пометка 2/2 и 1/2, отказ при разной частоте опроса, отчёт `--pool`; 2048 по умолчанию из конфига; папка как точка: все `*_raw.npz` прямо в ней по имени, без подпапок, отказ на папке здания с перечнем точек, имя папки вывода; проверка провала: две линии в 0,6 Гц обе находятся, у сильной линии и у склона резонанса нет лишних пиков, пики ровно на окне независимы, порог провала из конфига |
| `test_overview_figure.py` | объединение папки (каждая запись режется сама), поиск тона, отказ на смешанных ODR и пустой папке, пропуск чужих файлов; тон при 2048 и 4096 и порог по независимым отрезкам, режим поиска с порогом 0,01 для сравнения, поиск провалов, папки `nperseg_<n>` |
| `test_family_analysis.py` | кластеризация семейств |
| `test_main.py` | [[main.py]] запускается отдельным процессом (импортировать его нельзя: он сразу читает командную строку и открывает порт): отказ неоткалиброванной живой раскладке, раскладке replay не из таблицы режима и режиму без секции; тон 3,00 Гц между бинами (2,930 и 3,052 Гц при 2048) выходит в `med_freq_hz` ближе 0,02 Гц, решение остаётся на бине (`med_freq_bin_hz`), обе картинки строятся; кандидатов ниже порога нет на оси с доверенной частотой, на остальных не больше одного, со своим максимумом, поддержкой ≥ 50 %, ниже порога; `--show` отвергается без `--replay`, без `--virtual-mode`, с `all` и с двумя раскладками, а с одной раскладкой без экрана (Agg) отрабатывает и ничего не пишет; темы оформления: `--theme dark` красит сохранённый `figure2` в тёмный фон, без ключа фон светлый, `[visualization] theme` из конфига действует и перекрывается ключом, неизвестная тема в ключе и в конфиге — отказ |
| `test_control_run.py` | [[control_run.py]]: каждая точка отдельно и объединением при одном разрешении, без папок `nperseg_<n>`, пометка 2/2, пробы, пропуск объединения при разных ODR, повторный прогон заменяет вариант, сравнение «пропал / новый / остался», пары только в одной записи и на одной оси, отказ при нескольких nperseg в конфиге, проверка списка точек, папки списка в репозитории существуют; старый детектор: меняются только строки `[welch]`, группировка областей по оси и частоте, ключи одного детектора не принимаются с другим, replay точки из двух записей с тоном пишет доверенную область в «весь прогон» и «across runs 2/2», раскладки 8×8 и 4×4 в папке режима, порог раскладки из таблицы режима применяется и пишется в `result.txt`, отказ сравнивать прогоны разных детекторов; `--max-shared-sessions` пишется в секцию объединения и требует `--old-detector`; режим переключается только строкой `[welch] nperseg`, пороги идут в таблицу режима, прогон без раскладок берёт все раскладки режима, раскладка без порога — отказ |
| `test_false_alarm_check.py` | мало ложных пиков на белом шуме, пробы не меняют поиск и редко выходят «present», окрашенный шум сохраняет рост Z, линия из шумовой записи не копируется в форму шума, интервал Уилсона, командная строка, `--save-captures` пишет записи в формате `main.py` |
| `test_band_power.py` | синтетический горб находится на своей оси и не на других, сканирование ставит его на место и молчит в чистом шуме, база 5 Гц видит горб хуже мощности в полосе, систематика снижает z, стартовый пакет, отказ на смешанных ODR, опора по точке, папка как точка |

Проверка ложных пиков на сотнях шумовых записей идёт отдельным скриптом
[[false_alarm_check.py]], она дольше тестов. Результат 01.10.2026 при
базе 10 Гц: белый шум 0,7–1,7 %, окрашенный 1,7–4,0 % записей с ложным
пиком. Прежняя разовая проверка 16.09.2026 при базе 5 Гц: 3 из 300 при
1024 и 4 из 300 при 4096.
