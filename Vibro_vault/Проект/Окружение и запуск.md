# Окружение и запуск

## Какой Python

На этом компьютере библиотеки numpy, scipy, matplotlib и pyserial стоят
только в Python 3.13:

```
C:\Users\artal\AppData\Local\Programs\Python\Python313\python.exe
```

Команда `python` по умолчанию запускает Python 3.14, в котором этих
библиотек нет. Если скрипт падает с `ModuleNotFoundError`, запускайте его
полным путём:

```powershell
& "C:\Users\artal\AppData\Local\Programs\Python\Python313\python.exe" stable_spectrum.py results\<запись>_raw.npz
```

Установка зависимостей в другое окружение:

```bash
pip install numpy scipy matplotlib pyserial
```

## Кодировка

Отчёты содержат символ `σ`. Если вывод перенаправлен в файл, консоль
Windows в кодировке cp1252 падает на этом символе. Перед запуском задайте
переменную окружения.

PowerShell:

```powershell
$env:PYTHONUTF8 = "1"
```

Git Bash:

```bash
export PYTHONUTF8=1
```

## Откуда запускать

Все команды запускаются из корня репозитория
`C:\Users\artal\Documents\Claude\vibro-analysis`. Скрипты ищут
`config.toml` рядом с собой, а результаты пишут в папки относительно
текущей директории.
