## Доработки анализа

- [ ] **Честный порог для `--probe`.** Сейчас заданные частоты судятся по
      полному порогу Бонферрони по всей полосе. Для заранее выбранных
      частот порог должен учитывать только число проверок: около 3,1 для
      девяти проверок при alpha 0,01. См. [[Устойчивый спектр — метод]].
- [ ] **Окно базы для широких горбов.** Скользящая медиана 5 Гц съедает
      горбы шире 2–2,5 Гц. Нужен ключ или автоматический выбор, см.
      [[Разрешение nperseg]].
- [ ] **Мощность по полосе для широких структур**, вместо высоты одного
      бина.
- [ ] **Учёт прерывистых сигналов.** Горб 36 Гц включается на 17–25 %
      времени. Можно отмечать отдельно пакеты, где он есть, и анализировать
      их.
- [ ] **Предупреждение о близости к краю полосы**: кандидат 0,62 Гц сидит
      там, где у Z начинается рост шума 1/f.
