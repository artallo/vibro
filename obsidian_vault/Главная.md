# Виброанализ зданий — главная

Анализ слабых вибраций строительных конструкций акселерометром ADXL355.
Датчик подключён к ESP32, прошивка шлёт бинарные пакеты `VIB2` по UART,
анализ сделан на Python. Репозиторий: `artallo/vibro`.

> [!summary] Где мы сейчас (17.09.2026)
> - В полосе 0,5–15 Гц все вечерние записи содержат только шум датчика. Собственных частот здания пока не видно.
> - Выше полосы есть повторяемые сигналы техники: горб 36 Гц по Z и линия 49,1 Гц по X и Y.
> - Разброс результатов между прогонами объясняется шумом оценки, а не ошибкой алгоритма.
> - Подробнее: [[2026-09-16 Тюмень, три прогона]] и [[Почему результаты скачут]].

## Быстрый старт

1. Записать измерение, около 17 минут: [[main.py]]
2. Получить устойчивый спектр по записи: [[stable_spectrum.py]]
3. Посмотреть всю папку записей на одной картинке: [[overview_figure.py]]

```bash
python main.py --odr 250 --packets-per-session 8 --min-recommended-sessions 32
python stable_spectrum.py results/<запись>_raw.npz
python overview_figure.py "путь/к/папке с npz"
```

Перед первым запуском прочитайте [[Окружение и запуск]].
